Run the full chain on the task below. Work through every stage in order; each
stage operates on the previous stage's output.

1. **RIGOR** — pick the model/effort that matches this task's difficulty,
   verify facts instead of guessing, flag anything unconfirmed, and aim to
   produce the real deliverable — not a description of one.
2. **BRAINSTORM** — generate wide options including unconventional ones,
   cluster them into themes, flag the top 3 with a one-line reason each.
3. **EVALUATE** — score the top 3 against explicit criteria (state them —
   e.g. cost, speed, risk, reversibility), show the scoring, recommend one
   and name the tradeoff being accepted.
4. **DETAIL** — expand the winner with concrete numbers, ordered steps, and
   named tools/files/people. No filler, no "as needed," no vague qualifiers.
5. **EDIT** — tighten the prose: cut hedging, redundancy, and passive voice.
   Keep every fact and the original meaning intact.
6. **VERIFY** — before calling it done, state what would break this, what was
   actually checked (ran it, tested it, confirmed the number), and what is
   still unproven. Never report "done" without evidence.

Deliver the final result first. Then one line per stage on what it changed.
If no task is given, run the chain on the current problem in context.
