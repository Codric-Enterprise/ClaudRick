The difference a structured prompt makes

Without Power Pack

"Can you analyze this problem for me?"

You get a generic, rambling response that touches on several things but doesn't commit to a structure or surface the unknowns.
With /analyze

"Break the following down into its component parts: sub-problems, dependencies, unknowns, and the key decision points."

You get a structured breakdown: numbered sub-problems, a dependency graph, flagged unknowns, and clear decision points — actionable immediately.

What makes this different

⚙

Battle-tested prompts

Each command is a carefully crafted prompt structure — not a one-liner. They guide Claude to reason, structure, and verify before answering.

🔒

No secrets, no code

Plain Markdown files. No API keys, no executable code, nothing to audit. Safe to commit, share, and inspect line by line.

⚡

Works everywhere

Slash commands in Claude Code, copy-paste prompts in claude.ai, the API, Slack — anywhere you talk to Claude.

🛠

Dry-run & uninstall

Preview changes before installing. Clean removal with --uninstall. Automatic backup of existing commands.

👥

Team-ready

Drop the commands into any repo's .claude/ directory — they auto-load for every team member, no per-person setup.

📚

Guardrails built in

The power-practices skill auto-applies rules for model selection, truthfulness, prompt structure, and real deliverables.

Teams

Per-project

Commit commands to a repo's .claude/ directory. Auto-loads for everyone who clones.

cp -r commands/ .claude/commands/

Security & trust

  • Every command is a plain Markdown file — no executable code, no binaries
  • No API keys, tokens, or secrets anywhere in the pack
  • The installer backs up existing commands before overwriting
  • --dry-run lets you preview every change before it happens
  • --uninstall cleanly removes everything the installer added
  • MIT licensed — inspect, fork, and modify freely
