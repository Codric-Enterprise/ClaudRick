▸ Operating rules — the guardrails baked in
  • Right model for the job. Opus for hard reasoning, Sonnet for balance, Haiku for fast iteration.
  • Think before hard problems. Restate, weigh trade-offs, check reasoning, then answer with confidence.
  • Don't guess — verify. Separate what you know from what you infer; never fabricate links or citations.
  • Produce real deliverables. Make the file/artifact, don't just describe it.
  • Systematize the repeatable. Turn anything done twice into a workflow worth automating.
